# Changelog

本项目从 `1.0.0` 正式上线后开始按语义化版本管理。

## [Unreleased]

### Added

- 新增可由 Xcode 直接打开的原生 iOS/iPadOS 培训师端，Debug 默认使用 Mock 数据。
- 新增 `ios-api` HTTPS 网关、iOS 发布检查、App Store 草案材料和跨端文档。

### Changed

- 将可运行客户端统一整理到 `apps/`，共享 CloudBase 后端迁入 `backend/`，验证工具迁入 `tooling/`。
- 将正式文档、原型索引、发布材料和历史资料分区，并建立根级 `PROJECT_INDEX.md`。
- 公开微信工程改用 `touristappid`，CloudBase EnvID 和 seed 用户标识保持占位值。

## [1.0.1] - 已发布

### Fixed

- 修复开课重复点击可能生成多个 running 场次的问题。
- 修复“我的”页统计首次进入时闪现样例数据的问题。
- 修复首页昵称、头像与“我的”页资料不一致的问题，并按当前时段显示问候。
- 修复帮助与反馈未提交内容离开页面即丢失、提交后草稿未正确清空的问题。
- 修复签到、反馈、互动入口小程序码生成失败、复制入口误复制内部页面路径的问题。
- 修复参与者扫码或点击入口后无法正确解析签到、反馈、互动参数的问题。
- 修复复盘完成后状态未更新且未返回首页的问题。
- 修复活动库详情编辑入口不可用，以及交付/复盘详情误显示编辑入口的问题。
- 补充 `tooling/verification/` 校验工程，统一小程序代码 lint、单测和发布契约校验入口。

## [1.0.0] - 已发布

### Added

- 发布培训师工具箱小程序正式版。
- 支持备课、开课、签到、互动、反馈、复盘和我的页面主流程。
- 支持 `trainer-api`、`live-api`、`participant-api`、`review-api` 四个 CloudBase 云函数。

## 版本规则

- `1.0.x`：补丁版，只修线上问题、稳定性、文案和小范围体验问题，不引入新主流程。
- `1.x.0`：小版本，新增向后兼容功能或明显体验增强。
- `2.0.0`：大版本，涉及主流程重构、数据结构不兼容、用户操作方式明显变化或旧行为移除。
