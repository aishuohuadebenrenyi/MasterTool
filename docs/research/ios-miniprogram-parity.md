# 小程序培训师端调研与 iOS 对齐基线

## 产品边界

小程序共 21 条页面路由，其中 18 条是培训师工作流，3 条是参与者签到、反馈、互动页。iOS 首发迁移全部培训师页面；参与者继续通过 `live-api` 返回的小程序码进入微信，因此不在 iOS 重复实现。

## 页面与数据链路

| 模块 | 小程序页面 | 关键交互 | CloudBase action / 主数据 |
| --- | --- | --- | --- |
| 首页 | `home/index` | 欢迎信息、开课半弹窗、待开课/草稿/待复盘跳转 | `getHomeSummary`、`listTemplates`、`getProfile` |
| 备课 | `prepare/index` | 我的方案/活动库、搜索、三层筛选、新建模板、滑动操作 | `listPlans`、`listTemplates`、`listActivities` |
| 方案 | `plan/edit`、`plan/preview` | 草稿、确认、环节增删排序、活动选择、预览、设为模板、开课 | `getPlanDetail`、`getTemplateDetail`、`savePlanDraft`、`confirmPlan`、`savePlanAsTemplate` |
| 活动 | `activity-detail`、`activity-edit` | 收藏/置顶、编辑、删除、加入方案 | `getActivityDetail`、`saveActivity`、`updateActivityFlags`、`addActivityToPlan` |
| 现场 | `live/index`、`live/end` | 环节推进、主计时、提醒、签到/分组/积分/随机/互动/音效/独立计时/笔记 | `startSession`、`getSessionDetail`、`manualCheckin`、`saveGroupState`、`saveScoreState`、`saveRandomState`、`createInteraction`、`saveNote`、`endSession` |
| 反馈复盘 | `feedback/index`、`review/index`、`review/detail` | 反馈码、匿名开关、数据概览、问题框架、保存复盘 | `getSessionEntryCode`、`getDataOverview`、`listReviews`、`getReviewDetail`、`saveReview` |
| 我的 | `mine/*` | 资料编辑、记录、数据、设置、帮助反馈、关于、法律 | `getProfile`、`updateProfile`、`listTrainingRecords`、`saveSupportFeedback` |

全链路为：模板或空白方案 → 草稿方案 → 确认方案 → `live_sessions.sessionId` → 现场工具状态与参与者数据 → 结束 → 反馈统计 → 复盘 → 历史记录。`sessionId` 是现场、反馈、复盘的唯一关联键，CloudBase 是最终事实源。

## 视觉与交互规范

- iOS 亮色页面画布使用 `#F5F5F7`，品牌主色使用 `#4A7CF7`，Tab 选中态兼容小程序 `#4778F5`。
- 现场页为固定深色任务画布 `#1A1A2E`：环节进度、活动、主计时和关键提醒分层展示；工具 Sheet 继续使用系统自适应内容面。
- 主文字使用 `#1A1A2E`，辅助文字使用 `#8E8E93`，输入背景使用 `#F8F9FE`；暗色模式通过同一语义 token 提供适配色。
- 成功、警告和危险状态分别使用 `#34C759`、`#FF9500`、`#E5484D`；环节编号按蓝、绿、橙、紫、红、青、黄、灰循环。
- 信息卡为白色、约 16–24pt 圆角、轻阴影；状态使用胶囊标签；主操作为蓝色实心按钮。
- 小程序半弹窗映射为 iPhone `.sheet`，iPad 为右侧检查器或 modal；滑动操作映射为 trailing swipe/context menu；刷新映射为 `.refreshable`。
- iPhone 保留三 Tab 和紧凑纵向节奏；iPad 使用三项侧栏，内容页使用分栏，现场工具固定为检查器。
- iPhone 仅三个 Tab 根页面显示底部栏；所有 push 进入的业务二级页面隐藏底部栏并在返回后恢复。

## 初始差异矩阵

| 域 | 原 iOS 状态 | 本次对齐要求 |
| --- | --- | --- |
| 首页 | 仅开课按钮和复盘入口 | 补齐资料、待处理数量、模板开课入口与视觉层级 |
| 备课 | 无搜索、筛选、模板、方案操作 | 补齐双 tab、筛选、模板选择、状态/动作和活动库操作 |
| 方案活动 | 基础表单，未保存活动、预览、确认/模板 | 补齐方案生命周期、环节活动和详情编辑 |
| 现场 | 八个工具仅说明文字 | 补齐每个工具可编辑状态、持久化接口和二维码入口 |
| 收尾 | 统计和复盘为占位 | 补齐反馈入口、场次数据、复盘问题流与记录 |
| 我的 | 菜单与设置简化 | 补齐资料、记录筛选、帮助反馈、关于/法律与绑定码 |
| 数据 | Mock 与真实 action 名不一致 | 改为小程序同名 action，经 `ios-api` 路由；Release 禁止 Mock |

## 培训师表单字段基线

| 表单 | 小程序字段 | iOS 当前对齐行为 |
| --- | --- | --- |
| 方案编辑 | 方案名称、参与人数、客户名称、方案类型 | 名称和客户可输入；人数使用减号/数值/加号控件；方案类型只读；环节以彩色卡片支持名称、时长、活动增删和上下排序 |
| 活动编辑 | 活动名称、培训场景、难度、人数范围、时长、学习目标、规则说明、复盘引导问题、带领者 Tips | 字段、场景五选多选、难度三选单选及名称必填校验一致；新建、更新和删除复用现有 CloudBase action |
| 编辑资料 | 昵称，最多 20 字 | 仅保留昵称和 20 字限制，不增加组织等额外字段 |
| 帮助反馈 | 联系方式选填、问题反馈、500 字计数 | 字段、占位文案和字符限制一致；iOS 提交服务未接入前保持禁用并显示说明 |
| 结构化复盘 | ORID、4F、SSC；单题答案；上一题/下一题 | 使用相同 4/4/3 题目并保留跨框架答案；保存服务未接入前不伪造成功 |
| 反馈数据 | 匿名反馈 | 保留同名开关和“参与者无需展示姓名”说明 |
| 设置 | 左滑推进、右滑回退、双击延时、计时器声音、自动保存 | iOS 保留四项真实可配置偏好：左右滑动、双击加时和计时结束提醒；自动保存改为不可关闭的状态说明，微信历史账户显示“即将支持”且不进入无效表单 |
| 现场工具 | 签到姓名；分组方式/队伍数量；积分模式/原因；随机类型/允许重复；互动类型/标题/投票选项；计时模式/预设；笔记 | iPhone sheet 与 iPad 检查器共用同一页面级表单状态，关闭再打开不重置输入 |

参与者签到、反馈和互动输入仍由微信小程序承载，不在 iOS 重复实现。

## iOS 设置与现场快捷操作

- 设置页使用原生 `Form` 与系统开关，进入二级页后隐藏 Tab Bar，返回“我的”后恢复。
- 左右滑动需要至少 80pt 位移且横向位移明显大于纵向位移；首尾环节不越界，可见的上一/下一环节按钮始终保留。
- 环节计时按方案环节时长倒计时，支持开始、暂停、重置和增加 5 分钟；双击加时仅作用于计时器区域且可在设置中关闭。
- 主计时单击与双击互斥：单击只切换开始/暂停，双击只增加 5 分钟；新安装默认启用双击加时，已有安装沿用已保存偏好。
- 独立计时工具支持真实正计时与倒计时；倒计时归零只触发一次受偏好控制的声音与触感提醒。
- 现场环节、分组、积分和笔记变更沿用既有自动保存路径；保存失败会提示，但当前不承诺离线自动重试。
- iPhone 固定签到、分组、积分和工具箱四个入口；工具箱展示全部八项工具。签到、分组、积分、独立计时和笔记的关键动作固定在 Sheet 底部安全区。
- 退出现场会明确提示数据回退，并在确认后调用 `live.abandonSession`；结束培训仍使用 `live.endSession`。
