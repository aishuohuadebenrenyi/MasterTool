# 产品说明

MasterTool 是面向培训师的微信小程序工具，用于把培训交付中的备课、现场执行、参与者互动、反馈收集和复盘沉淀连接成一条可追踪的业务链路。

## 产品定位

- 帮助培训师快速准备培训方案和活动流程。
- 在现场提供签到、分组、积分、随机抽取、互动和笔记工具。
- 通过参与者反馈和培训师复盘形成可沉淀的数据记录。
- 使用 CloudBase 承接身份、数据、存储和云函数能力。

## 用户角色

- 培训师：创建方案、开课、控场、查看数据、完成复盘。
- 参与者：扫码签到、提交反馈、参与互动。
- 运营或管理员：准备模板、检查数据、协助发布和维护。

## 核心功能

### 备课

- 查看公共模板和个人模板。
- 将模板应用为草稿方案。
- 新建、编辑、确认和预览方案。
- 管理活动信息，包括场景、人数、时长、规则和复盘问题。

### 现场控制

- 基于已确认方案开始培训。
- 查看当前环节、流程进度和现场提醒。
- 让参与者扫码签到，或由培训师手动补录。
- 对已签到参与者进行分组、积分和随机抽取。
- 创建互动入口，支持投票、词云和承诺类提交。
- 保存现场笔记。

### 反馈与复盘

- 参与者通过小程序码进入反馈页。
- 培训师查看本场反馈和现场数据。
- 培训结束后创建复盘，记录观察、反思、改进和后续行动。

### 数据沉淀

- 每次培训形成独立场次。
- 签到、分组、积分、互动、反馈和复盘均绑定当前场次。
- 培训记录和数据详情支持后续查看。

## 当前技术状态

- 小程序工程位于 `wechat-app/`。
- 小程序代码位于 `wechat-app/miniprogram/`。
- 云函数位于 `wechat-app/cloudfunctions/`。
- 联调数据和发布检查脚本位于 `wechat-app-support/`。
- 正式发布前需要在本地配置真实小程序 AppID 和 CloudBase 环境 ID。

## 数据边界

- 培训师侧数据按内部 `userId` 和 `ownerId` 控制访问。
- 参与者提交只通过受控云函数写入。
- 业务集合默认不开放客户端直接读写。
- 关键写操作携带 `requestId`，用于处理重复点击和幂等请求。

## 后续方向

后续可按产品需要扩展 H5 管理后台、报告页或移动端工作台。当前正式交付以微信小程序为主线。
