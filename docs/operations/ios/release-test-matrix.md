# iOS/iPadOS 三轮发布测试矩阵

## 公共准入与缺陷门禁

- 被测包必须是同一 RC 分支的 Release/TestFlight 构建，连接测试 CloudBase，不得使用 Mock 或固定 token。
- 每条用例记录 build、设备、OS、窗口尺寸、网络、账号、结果、缺陷号和证据链接。
- R1 后 Blocker/Critical=0；R2 后 High=0；R3/外测时 crash-free sessions ≥99.9%，所有 P0/P1 已关闭或由产品和 QA 书面接受。

## R1：完整功能与真实数据

覆盖注册、邮箱验证、登录/恢复/刷新/注销/密码重置；资料跨冷启动；模板、活动、方案新建/编辑/确认；开课、扫码签到、八工具、环节切换、弱网重试、结束与放弃；记录、复盘、反馈、导出和删号；UGC 过滤、举报、屏蔽和运营处置。重点验证 iOS、小程序与 CloudBase 数据一致性以及失败不产生假成功。

## R2：兼容、性能、安全、可访问性

| 维度 | 最低覆盖 |
| --- | --- |
| OS | iOS/iPadOS 16 最低版本、当前主流版本、最新正式版；各至少一条真机或可信设备云证据 |
| iPhone | 紧凑、标准、Max；竖屏/横屏，浅色/深色，最大动态字体 |
| iPad | mini、11、13 英寸；全屏、Split View 窄/中/宽、Stage Manager、旋转、外接键盘 |
| 恢复 | 冷启动、前后台、系统杀进程、断网/弱网、令牌过期、跨设备登录 |
| 性能 | Release 真机冷启动 P50/P95、hang、滚动帧率、CPU、峰值/稳态内存、泄漏、能耗、包体 |
| 安全 | 鉴权/越权、限流、重放、TLS、日志/PII、依赖、SAST/DAST、数据导出与删除 |
| 可访问性 | VoiceOver、最大动态字体、对比度、Reduce Motion、外接键盘完成核心路径 |

冷启动验收为 P50/P95 均低于 2 秒；每个设备至少测 10 次，删除异常值必须说明原因。崩溃率使用 TestFlight/Organizer 的 sessions 口径，不用“本地未崩溃”替代。

## R3：Internal TestFlight RC 验收

验证全新安装、覆盖升级、登录恢复、迁移、网络权限、后台恢复、审核演示账号、隐私/支持链接、App Privacy 与实际请求一致。产品、iOS、后端、QA、安全/隐私负责人对同一 build 签字冻结。

## External TestFlight

至少覆盖目标用户、企业网络与常见真实设备，运行 10–14 天。每日归类崩溃、卡顿、功能、可用性和内容安全反馈；每次修复重新生成 build 并执行受影响路径加冒烟回归。最终以 crash-free sessions ≥99.9% 且关键反馈闭环作为提审门禁。
