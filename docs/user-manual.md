# 用户手册

本文面向培训师，说明 MasterTool 微信小程序的主要使用方式。

## 1. 进入小程序

打开小程序后，底部包含三个主入口：

- 首页：查看待处理事项、快速开课和复盘入口。
- 备课：管理模板、方案和活动。
- 我的：查看记录、数据、设置、帮助和关于信息。

## 2. 备课

### 使用模板

1. 进入“备课”。
2. 选择公共模板或个人模板。
3. 点击应用，生成自己的草稿方案。
4. 根据客户、人数、时长和活动安排调整内容。

### 编辑方案

1. 打开方案编辑页。
2. 填写方案名称、客户信息、人数和类型。
3. 增加或调整活动环节。
4. 保存草稿，或在确认无误后点击确认方案。

确认后的方案可以用于开始培训。

### 管理活动

活动用于组成方案流程。每个活动可记录：

- 活动名称
- 场景标签
- 人数和时长
- 操作规则
- 复盘问题

## 3. 开始培训

1. 从首页或备课页选择已确认方案。
2. 点击开始培训。
3. 系统创建当前场次，并进入现场控制页。

现场控制页会展示当前环节、进度、计时和工具入口。

## 4. 签到

### 参与者扫码签到

1. 在现场页打开“签到”。
2. 点击生成小程序码。
3. 让参与者扫码进入签到页。
4. 参与者填写姓名并提交。

系统会拦截同一场次内的重名签到和同一微信用户重复签到。

### 手动补录

培训师可在签到面板中输入姓名，手动补录现场参与者。

## 5. 分组、积分和随机抽取

### 分组

1. 确认参与者已签到。
2. 打开“分组”工具。
3. 设置分组数量或分组方式。
4. 生成并保存分组。

### 积分

1. 打开“积分”工具。
2. 选择对应小组。
3. 增加或减少分数。
4. 分数会保存到当前场次。

### 随机抽取

1. 打开“随机”工具。
2. 从当前场次已签到参与者中抽取。
3. 可按现场规则选择是否允许重复抽取。

## 6. 互动

现场支持创建参与者互动入口，包括：

- 投票
- 词云
- 承诺提交

操作方式：

1. 打开“互动”工具。
2. 创建互动题目。
3. 生成参与者入口小程序码。
4. 参与者扫码提交。
5. 培训师查看统计结果，并在需要时关闭互动。

## 7. 现场笔记

培训师可在现场页记录观察、关键反馈和后续复盘线索。笔记保存到当前场次。

## 8. 结束培训与反馈

1. 现场流程完成后点击结束培训。
2. 进入培训结束页。
3. 可引导参与者扫码提交反馈。
4. 培训师可查看本场数据，或进入复盘。

反馈包含评分和文字内容，会绑定当前场次。

## 9. 复盘

1. 进入复盘中心或培训结束页的复盘入口。
2. 查看本场签到、互动、反馈和现场数据。
3. 按复盘问题填写观察、反思、改进和行动。
4. 保存复盘后，场次状态更新为已复盘。

## 10. 数据与记录

在“我的”中可以查看：

- 培训记录
- 数据概览
- 本场详情
- 帮助与反馈
- 关于和法律文档

## 11. 常见问题

### 参与者扫不了码怎么办？

请确认云函数已部署、CloudBase 环境配置正确，并使用真机测试小程序码。

### 签到人数不足时能分组吗？

可以先手动补录参与者，也可以等待更多参与者签到后再分组。

### 同名参与者如何处理？

同一场次不允许重复姓名。现场可让参与者添加部门、编号或昵称区分。

### 反馈数据在哪里查看？

结束培训后进入本场数据或复盘页面，可以查看当前场次反馈统计。

### 设置会同步到云端吗？

当前设置页主要用于本地偏好。业务数据以 CloudBase 中的方案、场次、反馈和复盘为准。
