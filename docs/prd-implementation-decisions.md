# PRD 补充决策记录

日期：2026-05-27

## 二维码与参与者入口

- 内测期不接正式小程序码图片生成。
- 签到、反馈、互动先展示可用的小程序页面路径和口令，确保链路可以真实提交。
- 正式版再由后端调用微信小程序码能力生成图片，并将图片存储到对象存储/CDN 后返回前端。

## 音效资源

- 内测阶段不走 CDN 或后台配置。
- 小程序包内置少量通用默认音效，播放失败时降级为震动和 Toast。
- 后续若扩展音效包，需要确认授权来源，再评估 CDN/后台配置。

## 方案导出

- 内测阶段采用 Markdown 导出。
- 原因：Markdown 生成简单、可复制到飞书/企微/邮件，也便于后续服务端转换 PDF/DOCX。
- PDF 更适合正式交付物，但需要排版、分页、字体和文件预览链路，当前阶段成本更高。

## 培训师视角与客户视角

- 培训师视角：保留执行细节，包括时间控制、工具、控场提醒、复盘线索和内部提示。
- 客户视角：面向售前/交付沟通，突出课程目标、议程、参与体验和交付价值，不展示内部控场话术。

## 个人模板

- 支持将某个方案另存为个人模板。
- 个人模板不等同于系统流程模板；它来自培训师自己的历史方案，用于后续快速创建新方案。
