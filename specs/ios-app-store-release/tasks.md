# iOS/iPadOS App Store 正式发布实施任务清单

## 1. 执行口径

- 基线：2026-07-22 发布准备度审计；当前结论为 **NO-GO**。
- 优先级：`P0` 为提测或提报阻断，`P1` 为正式发布必做，`P2` 为范围条件项。
- 角色：`PO` 产品，`iOS` 客户端，`BE` 后端，`QA` 测试，`DES` 设计，`SEC` 安全，`LEGAL` 法务/隐私，`OPS` DevOps，`AH` Apple Account Holder，`ASO` 商店运营。
- 工时为净人时，不含苹果、税务、ICP、外部测试者等待时间；多人并行时不能直接换算为自然日。
- 默认首发不销售 App 内数字内容，Apple Pencil 不作为首发承诺。两项均须先完成范围门禁，结论变化时追加条件任务。
- 每个功能任务均须同步自动化测试、错误态、加载态和正式文档；不得用 Debug Mock 代替 Release 真实环境验收。

## 10. 关键路径与并行流

```text
REL-001～005
  ├─ 方案链路：REL-101 → 102 ┐
  ├─ 认证链路：REL-103 → 104 ├→ REL-105 → 106 → 107～110 → M2
  └─ 发布基线：REL-201～205 ┘                         │
                                                        ├→ REL-501 → 502 → 503 → 504 → 505 → 506
合规/资源：REL-401～407 ────────────────────────────────┘
质量基线：REL-206 → REL-301～305 ───────────────────────┘
```

- 真正关键路径是“范围/环境 → 方案与认证 → 部署/E2E → 缺失业务/UGC → 两轮全测 → TestFlight → 提审”。
- 图标、隐私文档、版权、元数据和 Apple 后台可与功能开发并行，但必须在 REL-505 前全部关闭。
- 单项完成不等于工作包完成；只有其验收证据、缺陷回归和相关文档同步后才能勾选。

## 11. 总工时与排期结论

- 各任务区间逐项相加的毛估算约 **630–930 人时**；扣除功能任务内已包含的共享测试/文档工作后，排期采用审计基线 **600–900 人时**。
- 若同时触发 IAP 与 Apple Pencil，追加 **80–140 人时**，并至少增加 2–3 个自然周及外部审核等待。
- 在 1 iOS + 1 BE + 1 QA 全职、跨职能兼职、环境和账号一周内到位的前提下：最早 2026-09-24 提交候选，现实正式发布时间为 **2026-10-09～2026-10-16**。
- 任一条件成立时需重排日期：CloudBase/Apple 后台未按 M0 到位、中国大陆 ICP 或税务银行需补办、商业模式改为 IAP、Pencil 改为首发必做、External TestFlight 稳定性未达到 99.9%。

## 12. 完成定义

- REL-001～506 所有适用任务完成，条件任务有明确“不适用”证据或已完成。
- 三轮全量测试相互独立且缺陷修复后重新回归，不以连续运行同一套单测代替。
- Release 真实环境不存在固定 token、Mock 回退、无效入口或用户可见占位。
- 真机 P95 冷启动 <2 秒，crash-free sessions ≥99.9%，安全 Critical/High 为 0。
- 产品、开发、测试、法务/隐私与 Account Holder 完成上线签字，App Store Connect 无阻断状态。
