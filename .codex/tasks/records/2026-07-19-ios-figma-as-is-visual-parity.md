# iOS/iPad Figma As-Is 全量视觉一致性修正

## 目标

- 以 iPhone 与 iPad 的 iOS/iPadOS 26.5 模拟器运行界面为唯一视觉基准。
- 检查并修正 Figma `Current / As-Is` 中全部页面、子页面、Sheet、半弹窗、Alert、卡片、筛选、导航和关键状态。
- 保留 Figma 原生图层与可编辑结构，不修改 SwiftUI 产品代码。

## 假设与边界

- 当前 Debug Mock 数据用于稳定复现所有可达状态；实际页面结构和样式以运行时为准。
- 本轮仅修改既有 Figma 文件和协作任务记录；不调整产品逻辑、接口或数据契约。
- To-Be/iOS 27 方向页面保留，不作为当前实现一致性验收对象。

## 成功标准

- 建立 SwiftUI 视图与运行时页面/弹层的完整清单，并与 Figma As-Is 一一映射。
- 关键布局、文案、色彩、字体层级、圆角、间距、按钮、卡片和状态与实际界面一致。
- iPhone、iPad、弹层/状态三组 Figma 页面完成结构审计，缺失字体为 0。
- 通过模拟器截图与 Figma 截图逐页/分组复核，并运行 `git diff --check`。
