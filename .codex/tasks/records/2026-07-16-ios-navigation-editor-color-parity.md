# 2026-07-16 iOS 导航、方案编辑与跨端色彩统一

## 目标

- iPhone 仅在首页、备课、我的三个根页面显示底部 Tab Bar。
- 方案编辑页按小程序的信息层级重构，并保留 iOS 原生交互与现有业务能力。
- 将小程序品牌色提炼为支持亮暗模式的 iOS 语义色彩系统。

## 边界

- 仅修改 `IOS-APP/`、本任务 iOS 文档和 `.codex/tasks/` 记录。
- 不修改小程序、CloudBase action、领域模型或数据契约。
- 保留工作区现有无关修改，不回滚、不顺手整理。

## 成功标准

- 所有二级业务页面隐藏 Tab Bar，返回根页面后恢复。
- 方案编辑支持基本信息、环节增删排序、活动增删、草稿保存、方案确认和开课。
- 亮色与小程序色彩一致，暗色保持可读；iPhone 与 iPad 构建通过。

- `swift test`
- iPhone / iPad Simulator Debug 构建
- Simulator Release 构建
- 导航、方案编辑与亮暗模式人工检查

## 实际修改

- 新增亮暗自适应的品牌、画布、卡片、输入、文字、状态和八色环节 token，并统一 App tint。
- 统一二级页面修饰：方案、活动、现场、反馈、复盘、我的二级页全部隐藏 Tab Bar，返回根页恢复。
- 方案编辑改为小程序同层级的基本信息卡、彩色环节卡、活动明细和固定底部操作区。
- 补齐环节上下移动、活动移除、重复活动保护以及动态字体下的单双列自适应。
- 同步 iOS 导航审计和小程序对齐基线文档；未修改后端、领域模型或小程序。
